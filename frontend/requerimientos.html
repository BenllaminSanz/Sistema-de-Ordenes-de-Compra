Cargar requerimientos desde Excel

Use la plantilla BASE GRAL (mismo layout que General / REQ / OC): Orden de compra, Fecha, N°, Fecha de solicitud, Tipo, No. proveedor, Proveedor, Total, Moneda, Usuario, Estado, Area, Departamento, Compañía, Tipo de servicio, Status. También se acepta el Excel legado de Contabilidad (Proveedor combinado + Depto). Puede ir en una sola hoja (Hoja1) o por tipo.

Solo se agregan REQ que aún no existan (mismo consecutivo / N° con sufijo A/B/C). Los que ya están en el sistema se omiten; no se borran datos. El botón Exportar Excel genera el mismo layout para reimportar o compartir con Compras.
