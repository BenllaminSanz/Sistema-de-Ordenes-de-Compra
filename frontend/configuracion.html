Notas importantes
  • La configuración guardada aquí tiene prioridad sobre las variables EMAIL_* del archivo .env.
  • La contraseña se guarda encriptada en la base de datos usando la llave SECRET_ENCRYPTION_KEY.
  • Después de guardar, los próximos correos (RFQ, verificaciones, etc.) usarán inmediatamente la nueva configuración.
  • El campo Copia y respuestas en cotizaciones usa el mismo correo como CC y Reply-To en solicitudes a proveedores.
  • La URL pública y el interruptor de notificaciones se guardan aparte: no se pierden si vuelves a usar el SMTP del .env.
  • Si desactivas la config de DB (botón "Usar solo .env"), el sistema volverá a leer las variables de entorno.
  • Para Office 365 / Outlook suele funcionar: Host smtp.office365.com, Puerto 587, Secure desmarcado.
